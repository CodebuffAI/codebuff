# Reporting Security Issues

If you believe you have found a security vulnerability in Openbuff, we encourage you to let us know right away. We will investigate all legitimate reports and do our best to quickly fix the problem.

Please contact the Openbuff maintainers via a private channel. If no private channel is listed yet, open a minimal GitHub issue asking maintainers to provide one; do not include sensitive details in public issues.

Please do not report security vulnerabilities through public GitHub issues.
