# PHP Idioms

- Preserve Composer autoloading, namespaces, framework conventions, and formatter/static-analysis expectations.
- Use strict types, typed properties, and explicit return types when the surrounding project does.
- Keep array shapes, DTOs, exceptions, and nullable values clear at API boundaries.
- Prefer dependency injection and existing service/container patterns over hidden globals.
- Avoid mixing presentation, persistence, and business logic unless the local framework pattern already does so.
