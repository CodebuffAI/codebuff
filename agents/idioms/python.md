# Python Idioms

- Prefer simple, explicit code and standard-library tools before introducing abstractions.
- Use context managers for resource lifetimes and keep exception handling narrow and purposeful.
- Follow existing typing style; add annotations where they clarify contracts without fighting local conventions.
- Preserve project formatting, import grouping, and test patterns.
- Use clear names and small functions; avoid hidden global state unless the codebase already centralizes it.
