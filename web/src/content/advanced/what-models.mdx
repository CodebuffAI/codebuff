# What models do you use?

Openbuff is BYOK: every agent is routed through the providers and models you configure in `openbuff.json`. The bundled agent definitions include default model identifiers, but those identifiers are just route keys for your local provider config — Openbuff does not supply hosted inference or a fixed model lineup.

## Orchestrator

The main agent ("Buffy") coordinates everything:

<MarkdownTable>
  | Mode | Route | Behavior | |------|-------|----------| | Default | `modes.default` / `base2` | Standard implementation flow with mandatory validation and review gates | | Plan | `modes.plan` / `base2-plan` | Planning-oriented flow without direct implementation |
</MarkdownTable>

## Subagents

The orchestrator spawns specialized agents for specific jobs: file discovery, code search, reasoning, editing, review, browser automation, and terminal commands. Each can be mapped to a different provider/model route in `openbuff.json`.

Default mode runs a single implementation pass with the standard reviewer gate and mandatory validation hooks.
